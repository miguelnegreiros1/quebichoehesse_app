# 🌿 Que bicho é esse? - Identificação de Animais - Estudo de API's

Aplicação web interativa para identificação de animais a partir de características observadas (grupo, cores, porte, morfologia e país), integrando **Frontend (HTML5, CSS3, JavaScript Vanilla)** e **Backend (Node.js + Express)** com integração à API **Animals API (Data and APIs)**.

---

## 🚀 Como Executar

### 1. Iniciar o Servidor
Abra o terminal na pasta do projeto:
```bash
cd "C:\Users\Miguel\OneDrive\Desktop\queBichoehEsse"
npm start
```

### 2. Acessar no Navegador
👉 **`http://localhost:3000`**

### 3. Configurar API Key (Opcional)
Se desejar integrar com a API remota, adicione sua chave no arquivo `.env`:
```env
PORT=3000
DATA_AND_APIS_KEY=sua_chave_aqui
```
